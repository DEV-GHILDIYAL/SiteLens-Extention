# SiteLens - Design, Accessibility & SEO Audit Suite

![SiteLens Header](WCAG/icons/icon128.png)

**SiteLens** is a comprehensive professional toolkit designed for web developers, designers, and accessibility auditors. It provides a powerful suite of features to ensure your website is WCAG-compliant, SEO-optimized, and visually consistent.

Developed by **DEV GHILDIYAL**, SiteLens streamlines the process of auditing complex CMS-generated layouts, marketing pages, and web applications.

---

## 🚀 Core Feature Modules

### 🛠️ Accessibility Audit
*   **Contrast Analyzer**: Real-time visual-based contrast detection for text and complex backgrounds.
*   **Manual Checker**: Ad-hoc color testing with live luminosity-aware previews.
*   **Image Audit**: DOM scanner for missing 'alt' attributes and screen-reader compatibility.
*   **Button Audit**: Validates button casing consistency and color contrast compliance.
*   **Image Integrity**: Multi-page scanner for duplicate and repeated images (including CSS backgrounds).

### 🔍 Navigation & Structure
*   **Hyperlink Detector**: Advanced crawler with auto-scrolling to capture and verify all links.
*   **Button Analyze**: Verifies redirect destinations and link validity.
*   **SEO Audit**: Checks meta tags, titles, and descriptions for search engine optimization.
*   **Font Audit**: Analyzes heading hierarchy (H1-H6) and typography structure.

### 🎨 Design & Assets
*   **Color Extractor**: Instantly extracts the full brand palette from any live website.
*   **Theme Gen**: Generates WCAG-compliant color variations for design consistency.
*   **Image Downloader**: Bulk extract and download images directly from the page.
*   **Screenshot Tool**: Capture Visible Area, Full Page, or Selected Areas with ease.

### 📝 Content Tools
*   **Content Check**: Verifies if specific document segments exist on-page (Supports .txt, .docx).
*   **Content Splitter**: Breaks complex text into logical heading/content blocks for auditing.
*   **Lorem Detect**: Scans for 'Lorem Ipsum' and other placeholder text.
*   **AI Self-Audit**: Simulates human-like auditing to verify dynamic UI flows.
*   **Alt Text Gen**: AI-powered SEO-optimized alt text generation for images.

## 🛠️ Getting Started

For detailed installation instructions and technical documentation, please refer to the [WCAG README](WCAG/README.md).

### Quick Install (Developer Mode)
1.  Clone this repository.
2.  Open Chrome and go to `chrome://extensions/`.
3.  Enable **Developer mode**.
4.  Click **Load unpacked** and select the `WCAG` folder.
